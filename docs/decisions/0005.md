# ADR 0005：启用后无需逐次确认的局域网访问

状态：Superseded by ADR 0007 · 2026-10-16；替代 ADR 0002 的逐会话确认与人工 SAS 要求。

背景：用户明确要求被控端无需每次确认即可被控，不需要账号体系。

决策：接入默认关闭；Host 本机一次启用、生成高熵访问密钥并选择查看/控制/文件权限。Controller 预先配置该密钥，后续自动校验与接受，无逐次弹窗。Host 显示活动连接与断开入口，可禁用/更换密钥，变更立即撤销已有会话。
不提供公网、账号或服务器。无人值守仅覆盖已登录且未锁定的当前用户桌面；不增加自启动服务、安全桌面控制或凭据绕过。

替代方案：每次确认不符合需求；完全无密钥会让同网段任意设备接管，因此不采用；账号服务器超出范围。
后果：需管理本地访问密钥、系统安全存储、失败限速与重放防护。TLS 身份必须与预配置密钥绑定，具体采用经过审查的标准认证机制，0.0.3 前补充设计与测试。当前骨架不实现或开放任何接入。
