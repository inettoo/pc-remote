# 范围
Windows 11 x64、同一直接局域网、一个活动控制会话、单显示器。
被控端单个自包含 EXE 自动安装与启动 Windows 服务；控制端单个 EXE 自动发现设备。无需预装 .NET、选择网卡、账号、配对口令或连接确认。
服务安装与防火墙规则创建需要 Windows 管理员权限；没有权限时正常请求提升，不绕过 UAC。
自动枚举 Up Ethernet/Wi-Fi 类型上的 RFC1918 IPv4；检查真实入站接口、同网段与无下一跳的同接口路由。拒绝公网、IPv6、通过网关路由的目标和本机/网络/广播来源。
不把 Windows 网络分类交给用户选择；同一直接子网是接入信任边界，服务启用后同网段控制端无需身份认证。
最终包括屏幕查看、键鼠与文件管理。当前已实现服务安装/发现、LAN TLS 直连、活动控制台用户代理、主屏 JPEG 基线与键鼠通道；并提供用户文件列表、上传、下载和取消，最大 1 GiB、目录有界，不删除/执行远端文件。双机/DPI/桌面权限矩阵尚未验收。
不做公网、NAT 穿透、云账号、注册/中继服务器、音频、多屏、锁屏与 UAC 安全桌面控制。
服务运行 Session 0；桌面代理在已登录用户会话运行，权限和 IPC 边界必须在实现时定义。
文件只暴露用户目录内明确的共享范围；不因服务是 LocalSystem 就让网络请求任意访问系统路径。
