# 范围
v0.0.1 只交付工程基础、主界面、模块边界和协议帧实现。
v0.1.0：Windows 11 x64、单显示器、一个活动会话、可信私有 LAN、手动地址回退、屏幕查看、预先授权后的键鼠和文件管理。
不做：公网地址连接、NAT 穿透、账号、服务器注册/握手、中继、自启动服务、锁屏/UAC 安全桌面控制、剪贴板同步、音频、多屏。
网络门禁：仅显式选择的私有网卡和同一链路子网；拒绝公网、默认路由穿越和 Public 网络配置。
仅 RFC1918 不足以证明同网段；后续实现需结合本机网卡前缀、路由和远端端点验证。IPv6 在首版禁用，loopback 仅测试。
Host 本机一次配置启用状态、访问密钥和权限（可选查看/控制/文件）；之后无需每次确认。默认关闭接入；开启后可按预设权限自动控制。必须显示连接方、权限、连接指示和断开入口。密钥吊销立即断开；校验失败或超时不得采集。密钥用操作系统安全存储保护，不写日志或发现报文。
文件仅暴露用户选定的根目录；规范化路径后检查边界，拒绝链接逃逸；写入临时文件、校验哈希后原子提交。
