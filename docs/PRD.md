# 产品规格
用户只做两件事：在被控电脑运行 Host EXE；在控制电脑打开 Controller EXE，选择出现的设备进行控制。
Host 自动安装/启动常驻 Windows 服务，后续随开机启动。控制端自动发现同一直接局域网设备，无网卡、账号、密钥或逐次授权步骤。
LAN 权限模型：服务启用即允许同一直接局域网控制端访问；不区分账号与设备身份。服务安装仍需要 Windows 管理员权限。
最终功能：屏幕查看、键鼠控制、文件管理。服务负责连接；交互用户代理执行桌面操作。锁屏/UAC 安全桌面与公网仍不在首版范围。
当前 0.0.2：单文件安装器、自动启动服务、自动发现；远控按钮禁用，清楚标记开发中。
验收：真实两台 Windows 11 电脑，运行单 EXE 安装后可发现；随后完成屏幕/输入/文件/断线/DPI 矩阵。
