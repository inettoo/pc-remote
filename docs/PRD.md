# 产品规格
为同一可信局域网内两台 Windows 11 电脑提供清晰、可撤销的屏幕查看、键鼠控制和文件管理。
角色：Controller 发起连接；Host 用户预先启用访问；一台电脑可兼任两者。
核心流程：发现或输入内网地址 → 自动校验访问密钥与预设权限 → 查看屏幕 → 按授权控制/管理文件 → 任一端断开。
无账号不代表无授权：Host 在本机一次启用并配置访问密钥和权限后，新会话自动校验，无需逐次弹窗。提供当前用户已登录、桌面未锁定时的无人值守访问；无 Windows Service。
v0.1.0 验收：两台真实 Windows 11 主机，发现、授权、画面、输入、文件完整性、断线恢复和 DPI 验收全部通过。
性能指标是后续实测目标，不是 v0.0.1 已实现的承诺。
