# UI 规范
Windows 11 Fluent，克制中性色与单一强调色，原生控件、系统主题和高对比；不堆渐变或阴影。
Segoe UI Variable/中文系统回退，正文 14、辅助 12、标题 28；4/8/12/16/24/32 间距，控件至少 36，圆角 8。
控制端首页只有自动发现状态与被控电脑列表；不显示网卡/扫描选项/账号/配对口令。未来设备卡片单击“控制”进入远控。
空状态说明在另一台机器运行 Host EXE；有网络变化自动重试，错误是信息提示而非用户配置任务。当前远控未实现时按钮明确禁用。
Host EXE 默认安装流程，Windows 要求时正常提升权限；完成提示服务已启动；不增加远控授权弹窗。
后续远控页：画面保持比例，状态和断开入口固定；断线遮罩，不用旧帧冒充实时。
后续文件页：双栏、进度/取消、冲突确认、受限共享根；不把服务权限暴露成任意系统路径。
验收：900×620 最小窗口、100/150/200% DPI、键盘导航、读屏命名与高对比。

v0.0.3：设备卡片“控制”打开远程窗口；上方固定设备名、画面状态与断开入口，画面按比例缩放、黑色边框不接受鼠标操作。过期画面或安全桌面显示遮罩并禁止输入。点击画面聚焦，失焦释放输入，UI 最多保存一份待渲染帧。
