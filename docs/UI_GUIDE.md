# UI 规范
视觉：Windows 11 Fluent，安静的中性色、单一蓝色主操作；避免渐变、大量阴影和装饰卡片。
字体 Segoe UI Variable，中文系统回退；正文 14、辅助 12、标题 28。间距 4/8/12/16/24/32；控件最小高 36，圆角 8。
亮色背景 #F5F7FA、面板白色、正文 #182230、辅助 #667085、强调 #245BDB；深色与高对比使用系统主题。
优先原生控件、键盘焦点、AutomationProperties.Name；状态通过文字与图标传达，禁止仅依赖颜色。
布局：左侧导航/产品标识，右侧标题、连接能力、设备列表；空状态解释下一步，不生成虚假设备。
六个页面规格：
- 设备：网卡选择、扫描、手动地址；加载/空/失败/过期状态。
- 连接状态：来源、密钥校验、预设查看/控制/文件权限、校验中/失败/成功；不要求 Host 逐次确认。
- 远控：画面保持纵横比，未授权提示、断线遮罩，禁止最后一帧冒充实时。
- 工具栏：状态、分辨率、预设控制权限、文件入口、固定断开按钮。
- 文件管理：双栏、路径、进度、取消、冲突确认、访问拒绝。
- 设置：网卡、共享根、日志、版本；接入默认关闭，本机启用并一次配置访问密钥和预设权限后自动接受合法连接。
v0.0.1 只实现设备页空状态及可切换的路线/设置说明；其余页面在对应里程碑实现。
视觉验收：100/150/200% DPI、最小 900×620、Tab 可达、系统高对比、屏幕阅读器命名。
